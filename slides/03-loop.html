20: 0:40 · 60: 0:40.

"The spec already says what done means. It does not mention each step in the code in detail. Plan mode is where the agent shows those steps, before it writes any code, and where we shape the architecture so the build goes the right way. Reading a plan takes 30 seconds. Reading a diff of about 1,500 lines takes an hour, and you will still miss things."
