Five phases, two owners

Accountability Never Moves.

Discovery Design Build Verify Release AI Options Drafts Code + tests Findings Summaries Human Priority Decisions Plan approval Acceptance Go / no-go

60: 2:30.

"Five phases. In each one the agent has a job, and a human still owns the decision. Discovery: the agent offers options, a human sets the priority. Design: the agent drafts, a human decides. Build: the agent writes code and tests, a human approves the plan. Verify: the agent reports findings, a human accepts. Release: the agent summarises, a human says go or no-go."

"Accountability never moves to the agent."

"If a team adopts only three things, adopt these. Structured requirements. Architecture-aware integration. Hard verification gates."

"Discovery and design are product and UX. The agent makes that work more important, not less."
